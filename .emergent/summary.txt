<product_requirements>
The goal is to integrate a Tinder-like movie/TV show matching feature into the FindFlix application, allowing partners to discover content together. The application needs to support:

-   **Account System**: Users can create accounts (email/password or Google OAuth), send/accept friend requests, and maintain a record of their viewing preferences.
-   **Configurable Content**: Partners can swipe on popular/trending titles, curated lists (by genre/preferences), or search results.
-   **Match Detection**: Real-time notifications for mutual right-swipes, followed by a summary screen displaying all matched titles.
-   **Session Management**: A single, open-ended swipe session per friend pair. When a friend is selected, users should have two options: Continue Swiping or View Matches.
-   **Enhanced Movie Details**: Matched movies should be clickable, navigating to a detailed screen. This screen must include movie/episode duration and a link to watch the trailer.

The implementation has proceeded with backend API endpoints for authentication, friend management, and swipe sessions, integrated with MongoDB for data persistence. The frontend includes screens for user authentication, friend interactions, the swipe interface, and a session summary, all mobile-optimized using React Native.
